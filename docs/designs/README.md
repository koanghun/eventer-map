# 설계 문서 (Designs)

이 디렉토리에는 주요 기능의 상세 설계 문서가 포함되어 있습니다.

## 📐 설계 문서 목록

### [이벤트 중복 검사 시스템](./event-duplicate-detection.md)
**작성일**: 2025-11-28

이벤트 중복 등록을 방지하기 위한 시스템 설계:
- 5가지 기준 (날짜, 거리, 시간, 출연자, 제목) 종합 판단
- 위도/경도 기반 정확한 장소 매칭
- 출연자 및 제목 텍스트 유사도 계산
- 엣지 케이스 대응 (같은 건물 다른 홀 등)

**핵심 기술**:
- geopy (좌표 거리 계산)
- difflib (텍스트 유사도)
- Haversine 공식
