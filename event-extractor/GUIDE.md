## 1. 가상환경 활성화

프로젝트 실행 전, 종속성 충돌을 방지하기 위해 가상환경(`venv`)을 반드시 활성화해야 합니다.

### 💡 실행 명령어
가상환경 활성화 스크립트는 **`source`** 명령어로 로드해야 합니다.

```bash
# bash/zsh 기준
source venv/bin/activate
```

> [!WARNING]  
> `./venv/bin/activate` 와 같이 직접 실행하려고 하면 `Permission denied` 또는 에러가 발생합니다. 반드시 `source` 를 붙여서 실행하세요.

활성화되면 프롬프트 맨 앞에 `(venv)`가 표시됩니다.

## 2. 필수 설정 파일

동작을 위해 다음 파일들이 프로젝트 루트 디렉토리에 위치해야 합니다.

| 파일명 | 필수 여부 | 설명 |
| :--- | :---: | :--- |
| **`.env`** | ✅ 필수 | API URL, 보안 토큰 등 환경 변수 저장 |
| **`credentials.json`** | ✅ 필수 | Google Cloud Console에서 발급받은 OAuth 클라이언트 보안 비밀 |
| **`fromAndKeyword.json`** | ✅ 필수 | 어떤 이메일을 수집할지 결정하는 필터 규칙 |
| `token.json` | 자동 생성 | 최초 실행 시 인증에 성공하면 자동 생성됨 (삭제 시 재인증 필요) |

### 🛠️ `.env` 예시
`.env.example` 파일을 복사하여 `.env`를 생성하고 필요한 값을 채웁니다.
```bash
cp .env.example .env
```

## 3. 메일 필터 규칙 설정 (`fromAndKeyword.json`)

가져올 이메일의 **발신자**와 **본문/제목 키워드**를 정의합니다.

### 📝 파일 구조 예시
```json
{
  "filters": [
    {
      "from": "members_info@pia.co.jp",
      "keywords": ["イベント", "公演"]
    },
    {
      "from": "another_sender@example.com",
      "keywords": ["티켓", "안내"]
    }
  ]
}
```

*   **`from`**: 발신자 이메일 주소입니다. (Gmail 검색 쿼리의 `from:주소` 로 변환됨)
*   **`keywords`**: 필터링할 키워드 목록입니다. 키워드가 많을수록 쿼리가 길어집니다.

## 4. 실행 및 옵션

### 🚀 기본 실행
가장 최근 메일부터 기본 수집 수량(5건)만큼 처리합니다.

```bash
python main.py
```

### ⚙️ 유용한 실행 옵션

#### A) 수집 메일 수 제한 (`--max-emails`)
한 번에 처리할 메일의 개수를 직접 지정합니다.
```bash
python main.py --max-emails 3
```

#### B) 드라이런 모드 (`--dry-run`)
**가장 추천하는 테스트 모드입니다.** 메일을 실제로 AI 분석하거나 API에 전송하지 않고, **수집된 메일의 내용만 콘솔에 출력**합니다. NEW 필터를 추가한 후 잘 동작하는지 확인할 때 유용합니다.
```bash
python main.py --dry-run
```

## 5. 동작 흐름 및 팁

1.  **메일 수집**: `fromAndKeyword.json`에 정의된 조건으로 Gmail에서 메일을 검색합니다.
2.  **AI 분석**: ChatGPT 등의 LLM을 활용해 메일 본문에서 `제목`, `일시`, `장소`, `출연자` 등을 추출합니다.
3.  **장소/출연자 해결**: 추출된 텍스트와 백엔드 DB를 대조하여 기존 데이터를 바인딩합니다.
4.  **백엔드 동기화**: 백엔드 API를 호출해 이벤트를 저장합니다. (자체 중복 필터링 작동)
5.  **완료 처리 (중요)**: 성공적으로 처리된 이메일에는 Gmail에 완료 라벨이 부착되어 **다음 실행 시 중복 수집을 방지**합니다.

> [!TIP]  
> 처음에 수집이 잘 안 된다면 `python main.py --dry-run` 으로 수집 쿼리(`from:... AND "키워드"`)가 원한대로 조회되는지 콘솔 로그를 통해 먼저 확인해 보시기 바랍니다.
