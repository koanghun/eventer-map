## 📝 일지 작성 규칙

1. **월별 파일 생성**: `YYYY/MM-MonthName.md` 형식
2. **날짜별 구분**: 각 날짜마다 `## YYYY-MM-DD` 헤더 사용
3. **작업 내용 기록**:
   - ✅ 완료된 작업
   - 🚧 진행 중인 작업
   - ❌ 실패/취소된 작업
4. **변경 파일 명시**: 어떤 파일이 수정되었는지
