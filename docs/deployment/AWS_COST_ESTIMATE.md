## 💡 비용 최적화 (Cost Saving) 팁

1. **ECS Fargate Spot 사용**: 백엔드 컨테이너 혹은 배치 작업에 Fargate Spot을 섞어 쓰면 온디맨드 대비 **최대 70%** 비용 절감이 가능합니다. (Fargate 비용 $15 ➡️ $5 수준)
2. **RDS 정지/시동 주기 설정**: 개발/테스트 중이라면 밤이나 안 쓰는 시간에는 RDS를 정지시켜 시간당 과금을 아낄 수 있습니다. (서버 시간당 약 $0.02)
3. **가입 방식 (Savings Plans)**: 1년 이상 가동이 확실해지면 Compute Savings Plans 가입을 통해 추가 20~30% 할인을 받을 수 있습니다.

## ⚡ 3. 백엔드 서버리스 (AWS Lambda) 전환 시 비용 및 특징

FastAPI 백엔드를 **AWS Lambda + API Gateway** 조합인 "서버리스"로 전환할 경우 요금 구조가 완전히 변합니다.

### 💰 예상 비용
- **AWS Lambda**: 호출 횟수 및 실행 시간 비례. 
  - Free Tier: 월 100만 건 호출 무료. (소규모 토이 프로젝트는 **사실상 $0**)
- **Amazon API Gateway**: HTTP API 기준 100만 건당 $1.00 내외.
- **결론**: ECS Fargate(~$15) 대비 **월 약 $10 ~ $12 추가 절감 가능**.

### ⚠️ 고려해야 할 트레이드오프 (주의사항)
1. **Cold Start (콜드 스타트)**: 한동안 요청이 없다가 들어오는 첫 요청에서 Lambda 초기화 시간(1~3초)으로 인해 첫 응답 속도가 느려질 수 있습니다.
2. **어댑터 필요**: FastAPI를 그대로 올리기 위해 **Mangum** 같은 AWS API Gateway 통합 어댑터 라이브러리 추가 및 설정 수정이 필요합니다.
3. **DB 커넥션 관리**: Lambda 인스턴스가 요청마다 늘어나거나 줄어들 때 배후의 PostgreSQL(RDS) 커넥션을 고갈시킬 위험이 있습니다. 안정적 운영을 위해서는 **RDS Proxy** 구축이 필요한데, 이 Proxy 비용이 월 ~$15 이상 발생하므로 오히려 배보다 배꼽이 더 커질 수 있습니다.

> 💡 **최종 가이드**: 
> 트래픽이 간헐적이고 동시 접속이 매우 적으며 요금을 극단적으로 아끼고 싶다면 **Lambda가 매력적**이나, DB 안정성과 일정한 응답 속도를 원한다면 기본 소형 컨테이너(Fargate) 가동이 오버헤드와 유지보수 스트레스가 적어 일반적으로 권장됩니다.
