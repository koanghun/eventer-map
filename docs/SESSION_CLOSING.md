# 작업 세션 마무리 절차

> 🤖 **AI 전용 문서**: 작업 세션을 마무리할 때 이 문서를 읽고 지시사항을 따르세요.

---

## 📋 개요

이 문서는 작업 세션 종료 시 프로젝트 문서를 자동으로 갱신하기 위한 절차를 정의합니다.
사용자가 이 문서를 AI에게 읽히면, AI는 다음 작업을 수행해야 합니다:

1. 오늘 수행한 작업 내용을 개발 일지에 추가
2. CURRENT_STATUS.md를 최신 상태로 업데이트

---

## 🤖 AI를 위한 실행 프롬프트

사용자가 이 문서를 제시하면, 아래의 절차를 따라 문서를 갱신하세요.

### Step 1: 세션 작업 내용 파악

오늘 세션에서 수행된 작업을 요약하세요:

1. **변경된 파일 목록** 확인
2. **주요 기능 추가/수정** 사항
3. **해결한 이슈** 목록
4. **기술적 의사결정** 사항
5. **다음 작업 권장사항**

### Step 2: 개발 일지 갱신

**파일**: `docs/logs/YYYY/MM-MonthName.md` (현재: `docs/logs/2025/11-November.md`)

**작업**:
1. 현재 날짜의 섹션이 이미 있는지 확인
   - 있으면: 해당 섹션에 내용 추가
   - 없으면: 새 날짜 섹션 생성

2. 다음 형식으로 작성:
```markdown
## YYYY-MM-DD

### ✅ [작업 제목]

**작업 내용**:

#### 1. [주요 작업 1]
- 상세 내용...

#### 2. [주요 작업 2]
- 상세 내용...

**주요 개선 사항**:
- ✅ 개선 1
- ✅ 개선 2

**기술적 의사결정**:
- **결정 사항 1**: 설명
- **결정 사항 2**: 설명

**이슈 및 해결**:
- 이슈 → 해결 방법

**다음 단계**:
- 권장 작업 1
- 권장 작업 2
```

3. 파일 경로와 변경사항을 구체적으로 기록
4. 코드 스니펫보다는 **무엇을 왜 했는지** 중심으로 작성

### Step 3: CURRENT_STATUS.md 갱신

**파일**: `docs/CURRENT_STATUS.md`

**업데이트 항목**:

1. **최종 업데이트 날짜**: 현재 날짜와 시간으로 변경
   ```markdown
   > 📅 **최종 업데이트**: YYYY-MM-DD HH:MM
   ```

2. **전체 진행 상황**: 진행률 바 업데이트
   - 완료된 작업에 ✅ 추가
   - 다음 작업을 ⏳로 표시

3. **완료된 주요 기능**: 체크리스트 업데이트
   - 새로 완료된 항목 추가
   - [x] 체크 표시

4. **알려진 이슈**: 
   - 해결된 이슈는 "해결된 이슈" 섹션으로 이동
   - 새로운 이슈 추가

5. **다음 단계**: 
   - 완료된 작업 제거
   - 새로운 우선순위 추가
   - 우선순위 재배치

6. **데이터베이스 현황** (변경 시):
   - 스키마 변경사항 반영
   - 마이그레이션 기록 추가

### Step 4: 검토 및 확인

1. 두 문서가 일관성 있게 업데이트되었는지 확인
2. 날짜, 파일 경로, 기술 용어가 정확한지 확인
3. 마크다운 문법 오류 없는지 확인

## 📝 갱신 체크리스트

AI는 다음 체크리스트를 따라 작업하세요:

- [ ] 오늘 세션의 주요 작업 내용 파악 완료
- [ ] 개발 일지 (`logs/YYYY/MM-MonthName.md`) 갱신 완료
  - [ ] 날짜 섹션 확인/생성
  - [ ] 작업 내용 작성
  - [ ] 기술적 의사결정 기록
  - [ ] 다음 단계 제안
- [ ] CURRENT_STATUS.md 갱신 완료
  - [ ] 최종 업데이트 날짜 변경
  - [ ] 진행 상황 바 업데이트
  - [ ] 완료된 작업 체크
  - [ ] 다음 단계 업데이트
- [ ] 두 문서의 일관성 확인
- [ ] 사용자에게 완료 보고

## 💡 작성 가이드라인

### 개발 일지 작성 시
- **구체적으로**: "UI 개선" ❌ → "InfoWindow를 표 형식으로 재디자인하여 가시성 향상" ✅
- **맥락 포함**: 왜 이 변경이 필요했는지, 어떤 문제를 해결했는지
- **파일 경로**: 백틱으로 감싸서 명확하게 표시 (`models.py`)
- **기술 용어**: 정확한 용어 사용 (Geocoding, N:N 관계 등)

### CURRENT_STATUS.md 작성 시
- **진행률**: 정직하게 평가 (과대/과소 평가 금지)
- **우선순위**: 실제로 다음에 할 작업을 우선순위 1로 설정
- **완료 항목**: 세부 항목까지 체크 (상위만 체크 금지)

## 🔄 사용 예시

### 사용자가 말하는 경우:

> "오늘 작업 마무리해줘"
> 
> "세션 종료하고 문서 갱신해"
> 
> "@[docs/SESSION_CLOSING.md] 읽고 실행"

### AI가 해야 할 일:

1. 이 문서의 지시사항을 따라 개발 일지와 CURRENT_STATUS.md 갱신
2. 완료 후 간단히 보고:
   ```
   ✅ 작업 세션 마무리 완료!
   
   - 개발 일지 업데이트: [날짜] 섹션 추가
   - 현재 상태 문서 갱신: 진행률 XX% → YY%
   
   다음 세션 시작 시 우선순위: [우선순위 1 작업명]
   ```
